# Can U Mog Zaid

Can U Mog Zaid is a browser camera game that tracks your face, zooms the camera view toward it, calculates a playful mog rate, and uploads snapshots to a leaderboard.

Local prototype of a small web app that shows your camera, detects your face, zooms to it, calculates a "mog rate", and uploads a snapshot to a public leaderboard.

IMPORTANT: Storing visitors' faces publicly may violate privacy laws and requires explicit consent. Do not deploy this publicly without informed consent and legal review.

Run locally:

```bash
npm install
npm start
# then open http://localhost:3000
```

Place an image for Zaid at `public/zaid.jpg` before starting to ensure Zaid appears on top of the leaderboard.
